# pairwise-particle-sort

爆炸烟尘压在角色脸前时反而把角色盖住，粒子排序按提交顺序走，透明混合结果随相机角度翻转；排序键用距离平方且只保留 16 位，远处粒子互相穿插；软粒子采样深度没做双边权重，贴地粒子边缘出现硬切；透明粒子写深度后又参与后续排序，前后的烟互相吞掉；GPU emit 与 sort 之间没有 fence，偶发整簇粒子消失；粒子池复用时速度没清零，新爆发继承上一簇的初速；子发射器再乘一次父速度，火星飞得比烟快十倍；暂停后 dt 累积到下一帧，恢复瞬间粒子瞬移；粒子与不透明物交叉处没有按深度重建软衰减；性能档砍掉排序后仍走透明混合，画面出现大块色斑。render/particle_sort.py 是核心，tests/test_particle_sort.py 15个红。要修的是：排序键改视图深度加稳定序号；软粒子深度双边加权；透明粒子不写深度；compute 后插 barrier；池复用清零速度；子发射器继承一次；暂停时冻结 dt；交叉处按深度重建；降级改 alpha 测试回退；排序分帧与双缓冲。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
